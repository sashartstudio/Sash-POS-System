SASH ART STUDIO Professional POS v2

Files:
- index.html
- style.css
- app.js

How to run in VS Code:
1. Create a folder, e.g. SASH-ART-STUDIO-POS-v2.
2. Put all 3 files in the same folder.
3. Open the folder in VS Code.
4. Open index.html in a browser, or use VS Code Live Server.
5. No npm or other installation is required.

Important:
The application JavaScript and styling were extracted from the uploaded index.html.
Existing POS functions remain in app.js; style.css contains the original embedded CSS.
